Console Documentation

Aruba-Style Security Operations Dashboard

This console acts as a Hewlett Packard Enterprise Aruba Switch skin repurposed to monitor cyber security logging interfaces (Suricata IDS, Tetragon eBPF kernel triggers, and Shuffle SOAR webhook response tasks).

Machine Learning Classifier

Telemetry metrics classify raw incoming logs using a scikit-learn Logistic Regression model. Predictions determine the severity levels and mapping references (CVE ID, CWE ID, and NIST Controls).

Integration Links

Linked interfaces query a local Uvicorn FastAPI backend which push enriched JSON objects to VictoriaLogs databases and Loki instances.
